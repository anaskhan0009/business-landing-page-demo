# Business Landing Page — Demo by Dinal Studios

**A complete agency / small-business landing page demo: hero, six services, why-us section, sample-work portfolio, three-tier pricing plans and a quote-request contact form — in one self-contained HTML file.**

Built to be re-skinned for any local business or agency client. No frameworks, no build step, no external assets — open `index.html` in any browser and it works on phone, tablet and desktop.

## Features

- Sticky responsive header with mobile hamburger menu
- Gradient hero with call-to-action buttons and delivery highlights
- **Six service cards** — business websites, online stores, landing pages, logo & branding, SEO setup, social media design — each with a starting price
- Why-us section (fast delivery, mobile first, fixed prices, easy handover)
- **Portfolio section of sample project types** — coffee shop site, restaurant site, online store, branding pack, social design, web apps — honestly labeled as demo project types, not real client work
- **Three-tier pricing plans** (Starter / Business / Store) with feature comparison and a highlighted popular plan; plan buttons pre-fill the contact form's project type
- **Quote-request contact form** — name, email, project type, budget range and project details, with a friendly confirmation message
- Studio contact info panel (email, working hours, remote worldwide)
- "Order a website like this" call-to-action linked to the Dinal Studios LaborX profile
- Fully responsive, mobile-first, modern gradient design

## Tech Used

- HTML5 (semantic sections)
- CSS3 (custom properties, grid, flexbox, gradients, text-clip effects, SVG icons, responsive media queries)
- Vanilla JavaScript (mobile navigation, plan-to-form linking, form handling)
